Dados e privacidade

Seus lançamentos são criptografados com AES-GCM antes de serem armazenados neste navegador. A senha não é salva. Não há conta, sincronização ou envio de dados financeiros para servidor.

Faça backups criptografados periódicos. Sem a senha, não será possível recuperar os dados. Limpar os dados do navegador pode apagar seus lançamentos.
